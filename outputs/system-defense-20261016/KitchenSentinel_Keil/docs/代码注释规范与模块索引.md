## 文件头和函数说明

本项目自编的后端、前端、网关、模拟器、脚本、迁移、测试和 STM32 工程均按同一规则维护。每个源文件开始说明“文件职责、主要功能、技术栈、模块联动、编写/修改日期”。日期采用《实习日志 全六周.xlsx》对应工作项的具体年月日，表示与日志的对应关系。真实采样、烧录和验收时间仍按测试证据记录。

主要函数、方法、组件、接口类型和重要事件在定义附近说明用途。重要算法进一步说明输入输出、状态、调用方、下游模块及边界。例如 ADC 失败会累计错误，不应把返回零视为有效测量；舵机比较值是控制指令，不是物理阀位；报警恢复不删除历史，也不代替人员确认。

后续修改时同步维护这些说明。原厂版权和模板说明保留，第三方 SDK 与依赖不批量改写。不支持注释的严格 JSON 配置通过本说明或相邻文档解释，保持文件格式有效。
