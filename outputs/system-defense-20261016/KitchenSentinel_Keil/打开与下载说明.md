# Keil / CubeMX 一体工程

交付日期：2026-10-16

打开firmware/stm32f103_hardware_test/CubeMX/MDK-ARM/KitchenSentinel_F103.uvprojx。选择Template只编译，Download目标F7执行真实下载与逐字节校验。

完整项目可直接使用现有.venv。独立包在本文件同层执行python -m venv .venv，再执行.venv\Scripts\python.exe -m pip install -r requirements-download.txt。保留目录嵌套，以便Keil定位本包.venv。安装Keil ARMCC5和原厂器件包仍属于开发工具环境。

CubeMX配置为firmware/stm32f103_hardware_test/CubeMX/KitchenSentinel_F103.ioc，与实际Core/Drivers工程位于同根目录。换位置后Rebuild All，再Go To Definition。

工程包不含热点密码、设备令牌、数据库配置、完整Flash备份或本机环境。烧录只覆盖应用区，保留板上离线队列及私有配置；首次在新板使用仍需完整项目配置网络。上电默认待机，开启采样须通过完整系统设备启用页。详细证据与边界见docs。
