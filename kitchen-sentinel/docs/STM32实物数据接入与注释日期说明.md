## 当前运行入口

在 `kitchen-sentinel` 项目目录使用项目 `.venv`：

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 'start.py' --hardware --skip-bootstrap
```

该入口统一启动后端和实物采集。网页地址通常为 `http://127.0.0.1:8000`；如端口被占用，以入口打印地址为准。登录信息在本机 `.runtime/access.txt`，不要公开该文件。

完整链路为 STM32 RAM 一致快照 → ATK-CMSIS-DAP/SWD → `gateway.swd` → FastAPI → MySQL → WebSocket → React 看板。硬件设备为 `stm32-001`，模拟器设备为 `kitchen-001`，令牌独立。

采集过程中不要同时启动其他 SWD 工具；再次烧录前先退出硬件运行入口。程序正常退出后 STM32 仍独立运行。默认 `python start.py` 启动模拟器，硬件模式需指定 `--hardware`。
